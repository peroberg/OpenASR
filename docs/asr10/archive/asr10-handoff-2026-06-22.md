```text

0x4e       -> f88f06 -> accepted-looking FC6818 handler
0x4f       -> f88f22 -> accepted-looking FC6818 handler
```

Vector matrix:


## Line-A / A000 Finding

A000 is explained and should not be treated as missing service payload.

Line-A vector #10 points to ROM `f882ca`:

```asm
f882ca: move.w D0,(A7)
f882cc: addq.l #2,2(A7)
f882d0: rte
```

Effect:

```text
writes D0.w to stacked SR/CCR
skips the A000 opcode
returns to the instruction after A000
```

In the `00bf18` sequence, `D0=0004`, so the post-RTE SR/CCR becomes `0004`.

Conclusion:

```text
A000 does not mutate queue, lowmem service state, or FC681x directly.
Do not add emulator behavior for A000 to solve the current blocker.
```
