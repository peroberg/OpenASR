  11. Prioriterad Lösningsplan

  1. Gör standalone MC68302 till source of truth för reset-CS, BAR/SCR, BR/OR, IPR/IMR/ISR, Timer1/2 och IACK.
  2. Ersätt MAME-harnessens MC68302 shadows stegvis med riktig MC68302-device eller SoC wrapper, med A/B-trace för reset, TRAP #0, CS3 och Timer2.
  3. Ersätt duart_panel_asr_candidate_r/w med MAME:s mc68681_device som SCN2681-kompatibel kandidat.
  4. Håll ASR-board glue separat: FC4800 odd-lane mapping, DUART clock, IRQ6 wiring, IACK/vector-policy.
  5. Håll panel-peer separat: TX-parser, RX-injektion, display/descriptorlogik.
  6. A/B-verifiera DUART timer IRQ6/vector 0x56 mot MC68302 Timer2 vector 0x46, så båda kan vara aktiva utan sammanblandning.
  7. Behåll FDC real-device-integration men ta bort/isolera synthetic TC efter regressionsjämförelse.
  8. Behåll ES5510 host-wrapper som bevisad lösning; flytta mot renare board select först efter test.
  9. Koppla ES5506 audio/sample/IRQ efter att CPU/DUART-tidskällor är stabila.
  10. Lämna ES5701 och SCSI tills deras adresser/signaler är bevisade.
